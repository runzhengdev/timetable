# 我的教务系统 · 课表管理

纯前端（HTML + CSS + 原生 JS，零依赖、零构建）。
**按周存快照 + 按学期归档**：每周一份独立课表，改这周不会动别的周；三个年级 × 两个学期各自一套，切换即换整套课表。

**当前数据：20 周全齐（143 个上课单元 / 11 门课 / 23.2 学分 / 328 小节）**

> 界面截图不入库，需要时本地打开 `index.html` 自行截图。

---

## 一、怎么用

双击打开 **`index.html`**（Chrome / Edge / Firefox / Safari 均可，不用装环境、不用起服务器）。

- 打开定位到「本周」；顶部 `第 N 周 ▾` / `‹ ›` 切周，手机可左右滑动切周。
- 有数据的周直接看；**没数据的周不会复制别的周**，提示「还没有课表数据」，可一键复制或手动加。
- 改课只改当前这一周；空周卡片上有「从其他周复制」，可复制最近有数据的一周再改。
- 「没有数据」和「确认无课」是两回事：内置数据里写 `[]` 表示确认无课（放假 / 调休）。
- 课表内容每次加载都以页面内置数据为准，浏览器只记住主题 / 显示模式；编辑是临时的，刷新即还原。
- 想把改动留下来：控制台 `jwxt.unlock()` 编辑后，「设置 → 导出 JSON」备份，或直接改 `assets/app.js` 里的内置数据再提交。
- 如果你在浏览器里看到的还是旧页面：Ctrl+F5 强刷（脚本带版本号，会自动取新文件）。

## 二、数据模型（为什么不循环）

```
terms = {
  '2026S1': { label:'2026 级 · 第 1 学期', termStart:'2026-08-31', totalWeeks:20,
              events: [ { type:'military', label:'军训', from:'2026-10-24', to:'2026-11-06' } ],
              schedule: { 1:[], 2:[], 3:[…unit…], 4:[…], 5:[], … , 18:[…], 19:[], 20:[] } },
  '2026S2': { … },  '2025S1': { … },  '2025S2': { … },
  '2024S1': { … },  '2024S2': { … }
}
```

- **学期容器**：三个年级 × 两个学期都建好了，切学期 = 换整套（课表 / 统计）。
- **学期内逐周快照**：`[]` = 确认无课（如第 5 周国庆、第 9–10 周军训），**没有这个键** = 还没记录。
- 每周课程互相独立：调课、停课、新开课只写进那一周，绝不套用到别的周。
- 只有「2026 级 · 第 1 学期」有真实快照（20 周全齐），其余 5 个学期是空容器。

### 扁平 + 一点点透明

- **单色半透明**：`hsl(h s l / 0.84~0.88)`，能隐约透出底层单元格（今日列的淡蓝、网格线），但不会发白

- 深色模式：半透明深色块 + 同色系左条；打印退化为浅灰实色

## 八、术语：小节 / 课次 / 连堂

| 说法 | 含义 |
|---|---|
| **小节** | 教务系统的 01–13 节，一节课通常占 2 小节 |
| **课次** | 一次上课。**「1-2 节」本身就是一次课**（2 小节），不是“两节” |
| **连堂** | 同一门课连续占 **≥ 2 个课次**：1-2 与 3-4 一起上（4 小节），或 3-4 与第 5 节连上（3 小节） |

界面上怎么体现：网格块内单课次只显示时间、跨课次显示 `· 连堂`；详情抽屉写 `01-02 小节（1 个课次）` / `03-04-05 小节（2 个课次 · 连堂）`；概览写 `22 小节 / 10 次课`。

## 九、功能

| 模块 | 能做什么 |
|---|---|
| **课表** | 主课表 / 助学班双轨道切换；周网格（周一~周日 × 7 大节，连堂自动合并）；1–20 周切换；当天列高亮；点课程看详情、编辑、删除；← → 切周、`T` 回本周；🖨 打印当前视图 |
| **统计分析** | 跨周去重学分/门数、已记录周、单周最多课节、每周课时分布（灰柱=无数据）、课程清单（出现周数 / 最近周小节） |
| **设置** | 学期切换、开学日、总周数、深浅主题、JSON 导入导出、重新同步内置数据、清空本学期 |
| **侧栏** | 今日课程（军训提示 / 上课中标记）、下一节课倒计时（跳过无数据周与军训日）、本周概览 |

**只读模式**：页面默认只读——顶栏显示「只读」角标，新增 / 编辑 / 删除 / 导入 / 清空等入口全部隐藏，课表可查看、可统计、可导出。需要修改时按 F12 打开控制台执行 `jwxt.unlock()`，角标变为绿色「编辑模式」；刷新页面自动回到只读。

| 控制台命令 | 作用 |
|---|---|
| `jwxt.unlock()` | 开启编辑（仅本次页面有效，刷新失效） |
| `jwxt.lock()` | 回到只读 |
| `jwxt.status()` | 查看当前是 `readonly` 还是 `editable` |
| `jwxt.restore()` | 清除本浏览器缓存并恢复内置课表 |

数据不落浏览器：每次打开都从仓库内置数据重建课表，只保留主题 / 显示模式偏好。没有服务器、没有账号同步，别人在页面上改动只影响他自己那一次浏览，不会影响你、其他访客或仓库内容。

**助学班（独立轨道）**：顶栏「主课表 / 助学班」切换。助学班按**日期列**展示 8 个周日（10-18、11-15 … 12-27）× 8 节（09:00–17:00）：上午 4 节英语（助学班，金色），下午 4 节政治（助学班，蓝色）。10-25 / 11-01 / 11-08 三个周日因军训停课。它有自己的节次时间表，不套用主课表的 7 大节；统计页单独一张卡片（2 门 / 8 天 / 16 次 / 64 节），不计入主课表学分。数据在 `assets/app.js` 顶部的 `ZSB` 常量。

## 十二、开发备注

- 单元字段：`id / name / credits / attr / kind / teacher / room / day / periods`（周次是容器，不在单元里）。
- 存储键：`jwxt.terms.v1`（{ active, terms }）、`jwxt.settings.v1`（主题 / viewMode）、`jwxt.wipedTerms.v1`（主动清空标记）、`jwxt.seedRev`（内置数据版本）、`jwxt.prevSchedule`（被覆盖前的旧数据留档）。
- 内置数据版本 `SEED_REV`：调大后，打开时用内置数据覆盖本学期（旧值写进 `jwxt.prevSchedule`），所以「第八周修正」这类更新能直接生效。
- 学期表 `TERM_SEED`（key 形如 2026S1，可带 `events:[{type,label,from,to}]`）；教师 `TEACHERS` 按课名映射，导入旧数据或缺教师时自动兜底。
- 导出 JSON：version 3，`{ app, model:"weekly-terms", activeTerm, terms, schedule }`；导入支持多学期包 / 旧单学期包 / 更早的“按周次范围循环”格式。

## 十三、设计决策：连堂课不拆

一条上课单元 = `periods: [3,4,5]`（连续小节），**不在数据层拆成三条**，只在网格里合并成一块显示。

1. **编辑一致性**：拆开后改名、换教室、改教师要同步改 3 条，漏一条就出现“同一节课两个名字”。
2. **统计干净**：学分按课程名去重算，节数按单元累加；拆开会让冲突检测、复制、清空都要额外处理相邻块。
3. **源数据只有段级时间**：教务系统给的是 08:30-09:50 / 10:00-11:20 这种分段，没有单节精确起止，硬拆会造出假时间。

什么情况**才**该拆：同一段连堂里换了教室 / 老师，或干脆是两门不同的课——这种教务系统本来就输出两条独立记录，导入后自然就是两块。

只想上其中两节（例如周五会计基础只上 03-04）：点课程 → 编辑 → 取消勾选「第5节」→ 保存。
